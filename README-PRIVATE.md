# Niamh's Jar: private version

Everything personal (messages, photos, videos) is encrypted with a long setup code. The public site only holds scrambled files.

## Upload to a NEW repo (don't reuse the old one: its history still holds the readable messages)
1. On GitHub, create a new repository (Public is fine; the contents are encrypted).
2. Upload all the files in this folder, flat, no folders. (`vault.json` is the encrypted jar.)
3. Settings -> Pages -> Deploy from branch -> main / (root).
4. Delete the old JarOfHearts repo (Settings -> bottom of the page -> Delete this repository).
5. Open `https://YOURNAME.github.io/NEWREPO/admin.html`, connect with a new token (Contents: Read and write, for the NEW repo), then paste your setup code once.

## On Niamh's phone (once)
1. Open the site in Safari -> Share -> Add to Home Screen.
2. Open the app from the home screen and paste the setup code. That's it: the phone remembers, and she never types anything again.

Keep the setup code out of the repo and out of any public place. If she ever gets a new phone or wipes the app's data, send her the code again.
