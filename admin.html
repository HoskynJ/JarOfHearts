Connect to GitHub

This lets you add photos, videos and hearts straight from this page. Your token is only stored in this browser.

  1. Open GitHub → New fine-grained token.
  2. Repository access: Only select repositories → pick the jar repo.
  3. Permissions → Repository → Contents: Read and write. Create the token and paste it below.

Unlock the vault

Everything in the jar is encrypted. Enter the setup code so this page can read and add to it. It stays only in this browser.

Add photos or videos

Pick one or more. Photos are shrunk automatically. Videos upload as they are, so keep them short (under about 40 MB is best). Multiple files become a swipeable memory.
